# 💖 Neon Heart Proposal

A cinematic and interactive love proposal website built with **HTML, CSS, and JavaScript**.

The experience starts with a mysterious intro, transforms floating particles into a glowing heart, and leads into a personalized proposal — ending with:

> **I LOVE YOU SOUMYA ❤️**

---

## ✨ Features

- 🌌 Cinematic dark/neon UI
- ✨ Animated floating particles
- ❤️ Real-time particle heart formation
- 💫 Glowing heart animation
- 💌 Interactive proposal screen
- 🏃 Playful moving **NO** button
- 💥 Particle explosion on **YES**
- 🎵 Background romantic music
- 🔄 Replay experience
- 📱 Responsive design for desktop and mobile
- ⚡ Smooth transitions and animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas
- Google Fonts
- CSS Animations
- JavaScript Particle System
